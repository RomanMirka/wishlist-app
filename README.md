# Спільний список бажань 💌

Сайт-вішліст для двох: додавайте товари з фото, ціною, посиланням і місцем продажу — і бачте список одночасно, у реальному часі. Дизайн — стилізація під естетику "робочого столу" кінця 2000-х (aero/скло), але в сучасному виконанні.

Стек: **React + Vite + Tailwind**, дані зберігаються в **Supabase** (безкоштовно), хостинг — **Netlify**.

---

## 1. Встановіть залежності

Відкрийте цю папку у VS Code, у вбудованому терміналі виконайте:

```bash
npm install
```

## 2. Створіть безкоштовну базу даних (Supabase)

Сайт сам по собі нічого не зберігає — йому потрібне сховище, спільне для вас двох. Це Supabase, займе ~5 хвилин.

1. Зайдіть на [supabase.com](https://supabase.com) → **Start your project** → увійдіть через GitHub/Google.
2. Натисніть **New project**. Вкажіть будь-яку назву та пароль до бази (можна автозгенерований), регіон — найближчий (напр. Europe).
3. Коли проєкт створиться, зайдіть у **SQL Editor** (в лівому меню) → **New query**.
4. Відкрийте файл [`supabase/schema.sql`](./supabase/schema.sql) з цього проєкту, скопіюйте весь вміст, вставте в редактор і натисніть **Run**. Це створить таблицю `items`, у якій зберігатимуться товари.
5. Увімкніть реальний час для оновлень: **Database → Replication** → знайдіть таблицю `items` → увімкніть перемикач.
6. Зайдіть у **Project Settings → API**. Скопіюйте:
   - **Project URL**
   - **anon public** ключ (не `service_role`!)

## 3. Додайте ключі у проєкт

У корені проєкту створіть файл `.env` (скопіюйте `.env.example` і перейменуйте):

```bash
cp .env.example .env
```

Відкрийте `.env` і вставте свої значення:

```
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-public-ключ
```

## 4. Запустіть локально

```bash
npm run dev
```

Відкрийте посилання з терміналу (зазвичай `http://localhost:5173`). При першому вході сайт запитає ваше ім'я — це просто щоб було видно, хто що додав чи купив (без паролів і реєстрації).

## 5. Викладіть на Netlify

Найпростіший спосіб — через Git:

1. Створіть новий репозиторій на GitHub і запуште туди код цієї папки.
2. Зайдіть на [netlify.com](https://netlify.com) → **Add new site → Import an existing project** → оберіть репозиторій.
3. Netlify сам підхопить налаштування з `netlify.toml` (команда збірки `npm run build`, папка `dist`).
4. Перед першим деплоєм додайте змінні середовища: **Site configuration → Environment variables** → додайте `VITE_SUPABASE_URL` і `VITE_SUPABASE_ANON_KEY` (ті самі значення, що й у вашому `.env`).
5. Натисніть **Deploy site**. Через хвилину отримаєте посилання типу `https://ваш-сайт.netlify.app` — скиньте його своїй половинці 💛

Альтернатива без Git — через Netlify CLI:

```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod
```
(CLI запитає токен Supabase — додайте змінні середовища так само через `netlify env:set VITE_SUPABASE_URL "..."` і `netlify env:set VITE_SUPABASE_ANON_KEY "..."`, потім задеплойте ще раз.)

## Як це працює

- Кожен товар — це "вікно" зі своєю шапкою: зелена кнопка **●** позначає товар як придбаний (і хто саме придбав), **✎** редагує, червона **✕** видаляє товар.
- Дані лежать у Supabase і оновлюються в обох браузерах одразу (через realtime-підписку), без перезавантаження сторінки.
- Ім'я користувача зберігається лише у вашому браузері (`localStorage`) — його можна змінити кнопкою знизу.
- Пошук і фільтри дозволяють швидко знайти всі, ще не придбані або вже придбані бажання.
- Доступ до списку не захищений паролем: будь-хто з посиланням на сайт зможе його переглянути й редагувати. Це навмисно спрощено для пари — просто не поширюйте посилання публічно.

## Структура проєкту

```
src/
  App.jsx                головна логіка й екран
  components/
    Taskbar.jsx           нижня панель (додати товар, ім'я, лічильник, годинник)
    WishlistCard.jsx       картка товару-вікна
    AddItemModal.jsx       вікно додавання товару
    NameGate.jsx           вибір імені
  lib/supabase.js          підключення до Supabase
supabase/schema.sql        SQL-схема таблиці items
```

## Можливі наступні кроки

- Додати завантаження фото напряму (зараз — лише посилання на зображення); для цього можна підключити Supabase Storage.
- Додати сортування за ціною.
- Додати push-сповіщення, коли партнер щось додав.
- Додати вхід через Supabase Auth і приватні групи. Це важливо перед тим, як давати посилання ширшому колу людей.

Якщо знадобиться допомога з будь-яким із цих кроків — просто попросіть.
